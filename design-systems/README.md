# Design systems (DESIGN.md)

Colección de 84 archivos `DESIGN.md` de [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (licencia MIT, ver `awesome-design-md/LICENSE`).

Cada carpeta (`apple`, `stripe`, `tesla`, `bmw`, `ferrari`, `airbnb`, `notion`, `vercel`, etc.) trae un `DESIGN.md` con colores, tipografía, espaciado y reglas de componentes de esa marca.

## Cómo usarlo

1. Elegí un estilo, por ejemplo `awesome-design-md/tesla/DESIGN.md`.
2. Copialo a la raíz del proyecto donde vas a trabajar como `DESIGN.md`.
3. Pedile al agente: "armá esta página siguiendo DESIGN.md".
